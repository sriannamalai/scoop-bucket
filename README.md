# Scoop bucket for cdb

[cdb](https://github.com/sriannamalai/CDB.CLI) is an interactive command line client for Apache CouchDB 3.2-3.5.

## Install

```powershell
scoop bucket add sriannamalai https://github.com/sriannamalai/scoop-bucket
scoop install cdb
```

## Update

```powershell
scoop update cdb
```

## Uninstall

```powershell
scoop uninstall cdb
```

## Platforms

The manifest carries release archives for:

- Windows, amd64 (64bit)
- Windows, arm64

## How this bucket is maintained

`cdb.json` is generated by goreleaser on every CDB.CLI release and must not be edited by hand. Any changes made directly to it will be overwritten on the next release.

Issues with cdb itself, or with this bucket, belong on the [main repo](https://github.com/sriannamalai/CDB.CLI/issues).
